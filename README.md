\# MOTO-AXIS (FarshGenerator)



Агрегатор высокопроизводительных мотоциклов. Платформа для тех, кто ищет свой предел на треке и на дороге. MVP-версия маркетплейса с полным циклом управления объявлениями.



\## 🚀 Основной функционал



\* \*\*Система аккаунтов:\*\* Регистрация и безопасная авторизация пользователей (Cookie Authentication + кэширование паролей алгоритмом SHA256).

\* \*\*Полный цикл CRUD:\*\* Создание, чтение, редактирование и удаление собственных объявлений.

\* \*\*Умный каталог и поиск:\*\* Мощная система фильтрации на базе LINQ (поиск по тексту, марке, классу, диапазонам цен, году выпуска, кубатуре, мощности, пробегу, типу привода и трансмиссии).

\* \*\*Пагинация:\*\* Постраничный вывод результатов каталога с сохранением состояния фильтров.

\* \*\*Работа с медиа:\*\* Загрузка фотографий мотоциклов с серверной валидацией форматов (.jpg, .png) и ограничением размера (до 5 МБ).

\* \*\*Безопасность данных:\*\* Строгая валидация входящих данных через DataAnnotations на стороне сервера.

\* \*\*Личный кабинет:\*\* Дашборд продавца для управления статусами (Активно, Продано, В архиве) и историей продаж.

\## ⚙️ Требования для запуска



1\.  Установленный \[.NET SDK 10.0](https://dotnet.microsoft.com/) (или совместимый).

2\.  Microsoft SQL Server (LocalDB или Express).



\## 📥 Установка и запуск



1\.  \*\*Клонируйте репозиторий:\*\*

&#x20;   ```bash

&#x20;   git clone \[https://github.com/your-username/moto-axis.git](https://github.com/your-username/moto-axis.git)

&#x20;   cd moto-axis/FarshGenerator

&#x20;   ```



2\.  \*\*Настройте строку подключения:\*\*

&#x20;   В файле `appsettings.json` проверьте `ConnectionStrings`. По умолчанию используется локальная база `(localdb)\\\\mssqllocaldb`.



3\.  \*\*Примените миграции (создание БД):\*\*

&#x20;   ```bash

&#x20;   dotnet ef database update

&#x20;   ```



4\.  \*\*Быстрый запуск:\*\*

&#x20;   Для быстрого старта используйте скрипт `run.bat`, находящийся в корне проекта. Он автоматически соберет приложение, запустит локальный сервер и откроет главную страницу в браузере по протоколу HTTPS.

&#x20;   

&#x20;   Альтернативный ручной запуск:

&#x20;   ```bash

&#x20;   dotnet run --launch-profile https

&#x20;   ```



\## 🗄 Структура базы данных



Проект использует реляционную модель со строгими связями (Foreign Keys):

\* \*\*Users\*\* — пользователи платформы.

\* \*\*Listings\*\* — объявления о продаже (связаны с продавцом и характеристиками).

\* \*\*MotorcycleSpecs\*\* — технические характеристики конкретного байка (связь один-к-одному с объявлением).

\* \*\*Brands \& Categories\*\* — словари марок и классов мотоциклов (связь один-ко-многим с характеристиками).

\* \*\*ListingImages\*\* — галерея изображений (связь один-ко-многим с объявлением).
